babatunde

Version 0.1.0 · Minecraft 26.2 · Fabric Loader 0.19.5 · 45 mods

Install once

  1. Install Prism Launcher and sign in with your Microsoft account.
  2. Download babatunde-prism.zip
  3. In Prism: Add Instance → Import → choose the zip → OK.
  4. Launch it. The first launch downloads every mod; later launches fetch only what changed.

Updates install themselves each time you launch. Settings you change yourself are kept; shared settings (such as world generation) follow the pack.
